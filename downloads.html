Verify your download

Checksums sit beside every artifact. Example for a macOS package:

shasum -a 256 podman-desktop.dmg # compare to published SHA-256

System requirements

  • macOS 12+ (Apple silicon or Intel)
  • Virtualization enabled
  • ~2 GB free disk for Desktop first run

Need an older release?

Previous stable artifacts stay in a version archive so the primary path stays uncluttered.

1. Install

Continue with Get Started docs for images, containers, and your first project workflow.
