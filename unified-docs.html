Before you begin

Install Podman and confirm the command is available in your terminal.

Go to downloads

1. Start a container

$ podman run --rm quay.io/podman/hello

The output confirms Podman pulled the image and started the container.

2. Inspect the result

$ podman ps --all

The command reference stays one click away for flags and advanced use.
