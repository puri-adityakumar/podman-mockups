Run your first container

This page explains the outcome, prerequisites, command, expected result, and next step without duplicating a separate landing-page tutorial.

Before you begin

Install Podman and confirm the command is available in your terminal.

1. Start a container

$ podman run --rm quay.io/podman/hello

The output confirms that Podman pulled the image and started the container successfully.

2. Inspect the result

$ podman ps --all

The command reference remains one click away for flags and advanced use.
